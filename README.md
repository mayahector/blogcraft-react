# BlogCraft React

A blog application built with React and Vite.

## Setup

1. **Install prerequisites:** [Node.js](https://nodejs.org/) 16 or later and npm.

2. **Clone the repository:**

   ```bash
   git clone https://github.com/mayahector/blogcraft-react.git
   cd blogcraft-react
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Start the development server:**

   ```bash
   npm run dev
   ```

   Open the URL shown in the terminal (usually `http://localhost:5173`).

5. **Build for production:**

   ```bash
   npm run build
   ```

   The output is written to the `dist` folder.

6. **Preview the production build:**

   ```bash
   npm run preview
   ```

   The preview runs at `http://localhost:8080`.

7. **Lint the code (optional):**

   ```bash
   npm run lint
   ```
